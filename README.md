## 📌 PT-BR (Português Brasil)

### 🔧 Funcionalidades
✔ Cria eventos no Google Agenda baseados em dados do Google Planilhas  
✔ Automatiza tarefas repetitivas de agendamento  
✔ Configuração simples e intuitiva  

### 🛠 Como Usar
1. Abra o Google Planilhas com seus dados
2. Clique em `Extensões` > `Apps Script`
3. No editor de script:
   - Clique em `Biblioteca` (+)
   - Cole o Script ID:
     ```plaintext
      1o16MnARvQ84VzWN_QNbKtIE_B8nfAn5di1DCN23HQW9n-tuIOCd56u6Z
     ```
     4. Clique em `Pesquisar` e adicione a biblioteca
5. Siga as instruções de configuração na documentação do script

## 🌎 EN (English)

### 🔧 Features
✔ Creates Google Calendar events from Google Sheets data  
✔ Automates repetitive scheduling tasks  
✔ Simple and intuitive setup  

### 🛠 How to Use
1. Open your Google Sheet with event data
2. Click `Extensions` > `Apps Script`
3. In the script editor:
   - Click `Library` (+) icon
   - Paste this Script ID:
     ```plaintext
     1o16MnARvQ84VzWN_QNbKtIE_B8nfAn5di1DCN23HQW9n-tuIOCd56u6Z
     ```
4. Click `Look up` and add the library
5. Follow the setup instructions in the script's documentation
